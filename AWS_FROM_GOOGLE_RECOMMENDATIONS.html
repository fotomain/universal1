Recommended Architecture: AWS Step Functions + AWS Batch (Spot Fleet)

Why AWS Batch + Step Functions beats all alternatives for running 1h to 40h isolated user workloads.

100% Tenant Isolation
Phase 1: Job Ingestion & Validation
API Gateway & Step Function
Receives pipeline request with user token, input parameters, and duration limit (e.g. 1h, 12h, 40h). Instantiates a distinct state machine execution.
Phase 2: Spot/Fargate Container Dispatch
AWS Batch Orchestration
Dynamically provisions an isolated container on AWS Spot EC2 (up to 70-80% discount) or ECS Fargate. Zero shared state with other users.
Phase 3: Strict Duration Enforcement
Dual-Layer Hard Timeout
Both AWS Batch jobTimeout and Step Functions TimeoutSeconds actively monitor runtime. If job reaches limit, it is SIGKILL'd instantly.
Phase 4: Output Persistence & Scale-to-Zero
S3 + CloudWatch + Teardown
Results, SQLite database states, and reports stream to Amazon S3. The compute instance immediately scales to zero with zero idle cost.

Multi-Layer Strong Duration Limit & Runaway Protection

How the architecture guarantees that no user job can ever exceed the 40-hour maximum execution limit under any circumstance.

Zero Runaway Billing Guarantee
1. AWS Step Functions State Timeout

Step Functions enforces a top-level orchestrator timeout via the TimeoutSeconds: 144000 attribute. If elapsed time reaches 40:00:01, Step Functions immediately forces an automated task termination state.

  • Independent from the compute node OS
  • Fires SNS alert to user and billing API
Primary Guard
2. AWS Batch Job-Level Timeout

AWS Batch natively supports the timeout: { attemptDurationSeconds: 144000 } parameter in the job definition. The AWS Batch daemon sends a SIGTERM followed by SIGKILL to the container.

  • Guaranteed container de-provisioning
  • Reclaims spot EC2 instance back to fleet
3. CloudWatch Alarm & Lambda Reaper

A background CloudWatch Event Rule runs every 5 minutes checking for any active task with runningTime > 40 hours. If found, it invokes a Lambda Reaper function to force-kill the task.

  • Ultimate safety net for network partitions
  • Zero possibility of zombie charges
Ready-to-Deploy AWS Step Functions Definition

Copy-paste state machine JSON definition for AWS Step Functions orchestrating the 40-hour isolated pipeline.

Amazon States Language (ASL)
step_functions_pipeline_definition.json 
{
  "Comment": "Per-User Isolated Pipeline with 40-Hour Hard Duration Limit",
  "StartAt": "ValidateUserDurationLimit",
  "TimeoutSeconds": 144000,
  "States": {
    "ValidateUserDurationLimit": {
      "Type": "Choice",
      "Choices": [
        {
          "Variable": "$.durationGuard.maxAllowedDurationHours",
          "NumericGreaterThan": 40,
          "Next": "RejectExceededDuration"
        }
      ],
      "Default": "RunIsolatedBatchJob"
    },
    "RunIsolatedBatchJob": {
      "Type": "Task",
      "Resource": "arn:aws:states:::batch:submitJob.sync",
      "Parameters": {
        "JobName.$": "$.pipelineExecutionId",
        "JobQueue": "arn:aws:batch:us-east-1:123456789012:job-queue/user-spot-queue",
        "JobDefinition": "arn:aws:batch:us-east-1:123456789012:job-definition/universal1-pipeline-job",
        "Timeout": {
          "AttemptDurationSeconds.$": "$.durationGuard.hardTimeoutSeconds"
        },
        "ContainerOverrides": {
          "Environment": [
            { "Name": "USER_ID", "Value.$": "$.userMetadata.userId" },
            { "Name": "S3_OUTPUT_PREFIX", "Value.$": "$.pipelineConfig.artifactOutputS3Prefix" }
          ]
        }
      },
      "Catch": [
        {
          "ErrorEquals": ["States.Timeout", "Batch.JobTimeout"],
          "Next": "HandleTimeoutCleanup"
        }
      ],
      "Next": "PublishSuccessNotification"
    },
    "PublishSuccessNotification": {
      "Type": "Pass",
      "End": true
    },
    "HandleTimeoutCleanup": {
      "Type": "Fail",
      "Cause": "Execution reached maximum configured duration limit (up to 40 hours hard limit)"
    },
    "RejectExceededDuration": {
      "Type": "Fail",
      "Cause": "Requested duration exceeds 40-hour architectural ceiling"
    }
  }
}
