More Gantt Input – what MS Project has and Universal 1 does not

Gap analysis of the Gantt chart / task table input of the app (kit8/pm) against Microsoft Project (desktop, 2016–2021 / Project Plan 3 and 5). Analysis only – nothing is implemented.

1. How to read this

Every row is a MS Project function that the app does not have, or has only in part. The column How it works in MS Project is the short description. The extra last column says what the app has instead, so a Partial row is clear; Missing means nothing similar was found.

Basis: the code and the READMEs of kit8/pm (scheduler view/project/scheduling.ts, tree, Gantt canvas, task window, dependencies, versions, exports) were read and searched by keyword on 2026-10-26. The running app was not opened, so a function that exists only as a hidden setting could have been missed.

2. What the app already does (so it is not in the table)

  • Schedule: automatic CPM (forward + backward pass), the four link types FS / SS / FF / SF with lag and lead in working days, links to stages, “start no earlier than”, Mon–Fri or 7-day week, critical path (colored), cycle detection, stage roll-up of start / finish / progress.
  • Outline: stages / tasks / milestones, WBS number (1.1.1), indent / outdent, drag and drop of rows, expand / collapse all, duplicate, delete with Undo / Redo (100 steps).
  • Gantt: drag a bar (move), drag the ends (resize), drag the progress knob, drag a link from a bar end, Day / Week / Month / Year zoom, pinch / Ctrl+wheel zoom, fit to screen, custom period, Today line, weekend shading, arrow shape, task color, progress % on bars, project progress line, hover or right-click commands.
  • Table: reorder / resize columns, per-column filter and sort (many operators), custom columns (text, date, boolean, integer, float), header colors, inline edit of Start / Finish / Duration / %.
  • Other views: Kanban, Network diagram (PDM) and network schedule (AOA), Versions (up to 4 saved versions drawn under the bars), subprojects, templates.
  • Exchange: JSON import / export, PDF of the screen, MS Project XML export.
  • Money and resources (richer than MS Project, on the Finances side): Time / Material / Expense / Revenue lines, work centers with calendars, busy check at Post, budgets, fact documents.

4. Suggested first picks

The gaps that cost users the most time in a plan editor, and that fit the existing engine (scheduling.ts, rowJSON keys, no new tables for most):

  1. B2 + B1 – Link / Unlink for the checked rows, then the Predecessors column. Cheapest way to build a plan fast.
  2. F1 + F2 – copy / paste of rows and cells (also from Excel) and fill down.
  3. A3 + A5 + E11 – the full constraint list, a deadline date, and the indicators column that shows them.
  4. A11 – holidays / exceptions from the existing calendar catalog, used by the schedule and shaded on the chart.
  5. C1 + C3 + C2 – per-task baseline, actual start / finish, variance columns on top of the existing versions.
  6. A1 – manually scheduled tasks (a flag in rowJSON, skipped by the forward pass).

Not suggested for an ERP-centred product unless asked: A6 / A7 (work-units-duration triangle – the money side already has its own quantity model), A16 (leveling), D4 (Team Planner), E9 (Timeline).

5. Not verified
