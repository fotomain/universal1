WBS How should the WBS treePath be structured for a single task project? Universal1 uses PostgreSQL ltree where projects are root labels, stages are depth 2, and tasks are depth 3. subpath(treePath, 0, 1) = projectGUID and nlevel(treePath) >= 2 constraint satisfaction.
WBS Which project settings from Project 1 must be preserved? Currencies (USD for budget, contract, accounting), UXUI right-click menu mode, calendar, customer invoice switch. rowJSON.customerInvoiceFunctionalityEnabled = true, currencyForBudget = 'USD'.
GENUS Why must exactly 1 line exist for each management genus? The enterprise spec enforces balanced visibility across all four cost/revenue vectors: Revenue, Material, Expense, Time. task_line_table contains exactly 4 lines with distinct rowParentGUID leaf codes.
GENUS How does equipment map between timeGenus and expenseGenus? Equipment can be plant lease/expense (expenseGenus) or operated machine hours (timeGenus). To keep 1 line per genus, Tamper lease is expenseGenus, Operator is timeGenus. Both timeGenus and expenseGenus have active financial lines.
MATH How is the exact count of 80-ft rail sticks calculated for 225 miles? A railway track requires 2 rails. 225 mi × 5,280 ft/mi × 2 = 2,376,000 ft ÷ 80 ft = 29,700 sticks. Exact quantity 29,700 sticks in task_line_table.
MATH What is the physical tonnage of the 29,700 rail sticks? 136 RE rail weighs 136 lbs/yd (45.33 lbs/ft). 80 ft = 3,626.7 lbs (1.81 tons). Total tonnage = 53,856 short tons. Material weight corresponds to realistic supply chain trainload logistics.
MARKET What justifies $1,850 per 80-ft rail stick within the $1,600-$2,200 range? $1,850 represents $1,020 per short ton of premium head-hardened AREMA continuous welded rail (CWR) steel. Price falls within prompt parameter constraint ($1,600 – $2,200).
MARKET How was the $650/hr Plasser 09-3X Dynacat tamper rate determined? Heavy railway maintenance machine dry/wet operating lease including wear parts, dynamic stabilizer plates, and service. Consistent with Amtrak & Class 1 maintenance-of-way rental schedules.
DOCS How do we guarantee that each document contains 100% full project amounts? Set quantities in PO, PR, VI to 29,700 sticks, 6,750 tamper hrs and 6,750 operator hrs; in Fact Input to 225 mi, 29.7k sticks, 6.75k tamper hrs, 6.75k operator hrs; in CI to 225 mi. DOCS How are register movements recorded during document posting? Each posting RPC invokes internal security definer register functions (e.g. project_status_register_order). Rows present in project_status_movements with matching registrator GUIDs.
LEDGER How does Monitor01 reflect the 5 posted lifecycle documents with full amounts? Ordered (PO), Received (PR), Used (Fact), Invoiced (VI), and Customer Invoiced (CI) columns match 100% of the plan. monitor01_view displays complete, equal figures across all operational and invoice report columns.
LEDGER How is project cost total rebuilt in the database? project_cost_rebuild(projectGUID) recalculates own and subtree costs from register movements. project_task_cost_total contains accurate costTotalForBudget = $59,973,750.
SCRIPT How to ensure the SQL script is 100% idempotent and safe to re-run? Use ON CONFLICT DO UPDATE for catalogs, and clean-insert project hierarchies with deterministic GUIDs. Running the script twice results in identical database state without duplicate key errors.
SCRIPT How should the shell command script handle CLI prerequisites? Verify supabase binary exists, detect linked project ref from JSON, and provide dry-run flags. RAILWAY#1_DATA_run.command executes cleanly on macOS Finder double-click.
ACTIVITY Which activity and direction does the budget item of each line get, and why? Cash flows of a construction contract are operating (IAS 7.14): receipts from rendering services (a), payments to suppliers (c), payments to employees (d). Costs are outbound, revenue inbound. 4 items: operatingActivity.revenueGenus inbound; .materialGenus, .expenseGenus, .timeGenus outbound.
ACTIVITY When would a line leave operatingActivity, and which key does it get then? A tamper that is BOUGHT is CapEx (IAS 7.16(a)) = investingActivity.materialGenus; a lease over 12 months puts its principal into financing (7.17(e)) = financingActivity.outboundPaymentGenus. Interest and dividends are policy items. The key is an allowed cell of kit8_budget_item_key_matrix(); financingActivity.timeGenus is refused by the trigger trg_budgetItemTable_key.
ACTIVITY How are the names in IFRS, D365 FO and SAP stored on the budget item, and how sure are they? webIfrsName (IAS 7 paragraph), d365foName, sapName in the budget item rowJSON. Only a few terms are confirmed by a vendor source: say so, never present the rest as verified. All three are filled for the 4 items; the report marks them indicative.
ACTIVITY How is the net operating cash flow budget proven? Inbound minus outbound of the budget items whose key starts with operatingActivity: $270,000,000.00 - $59,973,750.00. The SQL guard passes and prints $210,026,250.00; run.command --verify shows the rows 2c. Cash flow.

The seed deleted from task_line_plan, which the schema replaced by task_line_plan_movements + task_line_plan_timeline; a stale statement stops the whole script. 4. Key Engineering Best Practices for AI Pair-Programming

✅ Deterministic GUID Allocation

Always assign clear, deterministic UUID ranges for seeded enterprise entities (e.g., a1000... for projects, b1000... for task lines, c1000... for document headers). This guarantees exact referencing across multiple scripts and prevents orphaned foreign keys.

✅ Full Project Amount Consistency

When the business requirement dictates full project amounts, ensure that quantities match across Purchase Order, Product Receipt, Fact Input, Vendor Invoice, and Customer Invoice without partial balances left unaccounted for in the project ledger.
