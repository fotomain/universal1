F0b – can a BROWSER send the bytes to a Google resumable session url?

Result of the run of 2026-11-11: yes – in chunks with a Content-Range header (every answer, also the last one with the file id, is readable). A single PUT of the whole body also arrives at Google, but the browser cannot read its answer (no CORS header). The app therefore uploads in chunks (multiples of 256 KB) and finds its file by the uploadId property (upload_finish).

Serve this page from the origin the app will use, e.g. python3 -m http.server 8099 in this folder, then open http://localhost:8099/f0b_cors_test.html. Google allows the PUT from a page only if the session was opened with that page's Origin header – the Edge Function passes it on (upload_session).
