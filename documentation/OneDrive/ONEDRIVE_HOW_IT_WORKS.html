2. What changes in the plan

  • Check 1 decided the upload design: browser → OneDrive directly (no fallback through the function). Chunk = 5 MiB (a multiple of 320 KiB); 202 and 308 both mean "send the next fragment"; resume with GET on the uploadUrl.
  • Finish without custom properties is simple: the last answer is readable, so the app sends the itemId to upload_finish; the function reads the item (GET /me/drive/items/{id}), checks that its parentReference.id is the folder it recorded and that size equals the declared size, and registers it. The "find by name + size + time" rule stays only as a fallback when the browser lost the answer.
  • Delete is one call: permanentDelete works on a folder with content (204). The OneDrive adapter does not need the bottom-up order Google needs.
  • Name rules: refused by a personal account: trailing dot and ? (and the other reserved characters of the documentation); the sanitising rule of the plan stays. Conflict is reported when the session is created (409), so the function sees it before any byte is sent.
  • Path limit is 400 characters of URL path: the adapter refuses a longer chain with a clear message (our chains are about 150).
  • Refresh token: the new token is a different string and the old one still worked once more – the adapter must still save the new one every time (the documented rule); the 90-day sliding rule is measured in OD7 with the function.

3. Not run / still open

  • Work / school account: the same checks (especially 8a names with # % ~, 7 versions (500), permanentDelete, the unlicensed-drive state) need a work account – none is available yet.
  • Disconnect screens (spike 10) and files shared with the account (spike 11): manual; the consent page already stated "including files shared with you".
  • Refresh token lifetime of a Web registration (90 days, sliding) and the function streaming a 100 MB file: measured in OD7 with the real function.
  • Housekeeping: the account's app permission now includes Files.ReadWrite for UNIVERSAL1 Supabase login; it can be removed at the Microsoft account's app permissions page. The redirect address http://localhost:8765/onedrive_spike.html (Single-page application) was added to the registration for the spike and can be deleted.
