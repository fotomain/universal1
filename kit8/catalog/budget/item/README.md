# Budget items

`budgetItemTable` - the budget items (articles) a task line is budgeted as. The folder structure is the one of `managementGenusTable` (two levels in one table: **folders** level 1, **items** level 2):

```
costsBudgetFolder     > timeBudgetItem, materialBudgetItem, expenseBudgetItem
revenuesBudgetFolder  > revenueBudgetItem
paymentsBudgetFolder  > inboundPaymentBudgetItem, outboundPaymentBudgetItem
```

rowGUID = the code · rowOwnerGUID `budgetItemCatalog` · rowParentGUID = the folder ('empty' = the row IS a folder) · rowJSON `{ title, description, managementGenusItem, budgetItemGenericKey, direction, isCorrection, isPolicyItem, webIfrsName, d365foName, sapName }`.

**`rowJSON.managementGenusItem` is obligatory on an item** = the `rowGUID` of a level 2 row of `managementGenusTable` (`timeGenus`, `materialGenus`, ...), the genus the item belongs to
(a Time task line will offer the items of `timeGenus` only: `budgetItemsOfGenus`). It is enforced in three places:
SQL (CHECK: set; trigger: the row exists and is a genus item, not a genus folder), the table (the Genus column cannot be empty, `budgetItemGenusError` refuses a value that is not a genus item,
a new item gets the genus of its folder's items, else the first genus) and a red warning on the screen for any item that has none.

**Activity and direction (PART 32, `documentation/ACTIVITY_GENUS.html`).** `rowJSON.budgetItemGenericKey` is **obligatory on an item** = `'<activity>.<management genus>'` (operating / investing / financing × the genus of the item;
only 14 of 18 cells are allowed, `budgetItemKeyModel.ts`, README of `kit8/catalog/management/activity_genus`) and `rowJSON.direction` = `inbound` | `outbound` (default = the direction of the key; an item marked
`isCorrection` may reverse it). `webIfrsName` / `d365foName` / `sapName` = how the item is named in IFRS (IAS 7 paragraph), Dynamics 365 FO and SAP; `isPolicyItem` = IAS 7 leaves the activity to the company (interest, dividends).
Enforced by SQL (trigger `kit8_budget_item_check_key`: a missing key becomes `operatingActivity.<genus>`, a missing direction the default; CHECK `budgetItemTable_key_chk` after the backfill) and by the screen
(Activity column = only the activities of the genus, `computeRowJSON` = `budgetItemKeyPatch`, red warning for an item without a valid key). **32 possible budget items** (the tree of the design document: 14 operating, 11 investing,
7 financing, each with Web + IFRS / D365 FO / SAP) are seed rows of `start3_sql_insert_missing.sql` PART 32.

- Run `kit8/sql/init/create_budget_item_table.sql` AFTER `create_management_genus_table.sql` (table, RLS for signed-in users, realtime, the 9 default rows generated by `INSERT … SELECT` from the genus rows; `delete_budget_item_table.sql` removes it).
- Route `/catalog/budget/item/list` (drawer **Budget Items**) → `PMBudgetItemCRUD.tsx`: `FolderTreeReusable` with the FOLDERS beside a `ReusableTable` with the ITEMS (pick a folder = its items; no subfolders).
  Columns: Budget item, Code, Folder, Management genus, **Activity**, **Direction**, **Correction**, Business unit, Description, **Web + IFRS**, **D365 FO**, **SAP**, **Policy**.
- **Editing is on by default** (`noCrud={false}`); the lock button in the header (or `<PMBudgetItemCRUD noCrud />`) makes it read-only. A new item goes into the picked folder (or the first one);
  folders are created / renamed / reordered / deleted in the tree (`useBudgetItemTree`; deleting a folder deletes its items; "new subfolder" and a folder dragged into a folder are refused).
