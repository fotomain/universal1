# BIM examples

* `example1/Structure_Walls.ifc` - "Structure Walls" of https://github.com/viktor-platform/ifc-sample-models (IFC4, Revit 2024, 58 walls, 12 storeys of which 4 hold walls, in feet). That repository has no licence file: keep it as a private test.
  Project GUID of the example: `aabd1dde-97e6-4359-97e4-0efcb847589b`.
* `example1/out/` - what `py/bim/server/ifc_to_bim.py` made of it: `bundle.json` (model, storeys, chunks, elements, properties), `project_data_<guid>.json` (the project exchange file: 4 stages + 58 tasks, no links, no lines),
  `chunks/<sha256>.bimc` (4 chunks, 37 088 bytes). It is the golden file of `__tests__/bim` and of `kit8/docker/test_bim_example1.sh`.
* `example1/example1.demo.json` - the same, in one json (chunks as base64) for the offline demo `/pm/bim/example`.
* `example2/Duplex_A_20110907.ifc` - the buildingSMART **Duplex Apartment** (architecture; IFC2X3, Revit 2011, metres, CC BY 4.0: keep the attribution), from https://github.com/buildingsmart-community/Community-Sample-Test-Files (Git LFS, 2 380 763 bytes). Project GUID `a1800750-c76d-401b-b866-e4aaf1998a7c`. `example2/out/` = 4 storeys (T/FDN, Level 1, Level 2, Roof), 215 elements (56 walls, 21 slabs, 14 doors, 24 windows, 61 furnishing, 13 coverings, 8 beams, 7 footings ...), 4 stages + 215 tasks, 4 chunks = 287 244 bytes, worst difference to the IFC 0.2 mm; `example2/example2.demo.json` = the offline demo json. Test `__tests__/bim/bimExample2.test.ts`. Docker database flow: `kit8/docker/test_bim_example2.sh` (17 checks, ALL OK). Demo: `/pm/bim/example?example=2` (two buttons switch between the examples; seen in a browser 2026-11-20: stage highlight and the local database work).
* Example 3 (Schependomlaan) and **example 4 (Sixty5, a large model)** are NOT stored in the repository (49 MB / 343 MB): the importer fetches them by address (`BIM_EXAMPLES` in `kit8/pm/bim/model/bimModel.ts`). Example 4: project `7c1d5a30-4b8e-4f6a-9d21-5e0b6a3f8c14`, Hugging Face mirror of buildingSMART's `SDK - S1` (CC BY 4.0, holder unspecified), sha256 `e91ddbbd672bbde946af14631de4c732f0cf8a7cfae5dbbf06fbeab03b5c46df`; 19 storeys, 16 650 elements, 1 639 grouped tasks, 19 chunks = 23.7 MB; database test `kit8/docker/test_bim_example4.sh`.
